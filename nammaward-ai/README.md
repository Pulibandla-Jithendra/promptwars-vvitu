## 🎯 What is NammaWard AI?

NammaWard AI is a civic-tech prototype that empowers citizens to report and track local issues — garbage, potholes, drainage, streetlights, and water supply — in their ward. An AI analysis layer automatically categorizes complaints, assesses priority, and suggests recommended actions to civic authorities.

### 🤖 AI Features (Demo Mode)

The AI analysis is demonstrated using a rule-based simulation that:
- **Categorizes** complaints into municipal departments
- **Assesses priority** based on keyword analysis (critical/high/medium/low)
- **Generates summaries** of reported issues
- **Suggests actions** with recommended response times

> ⚠️ **Disclosure:** This prototype uses simulated AI analysis for demonstration purposes. It is not connected to any real municipal authority or live AI service.

## 🚀 Getting Started

```bash
cd nammaward-ai
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📦 Build for Production

```bash
npm run build
```
