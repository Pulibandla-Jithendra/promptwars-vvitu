# NammaWard AI

The complete project overview, implementation-status table, problem statement, workflow, privacy notes and deployment instructions are in the [repository README](../README.md).

## Local development

From this directory:

```bash
npm ci
npm run dev
```

Run `npm run build` to type-check and create the production bundle. The current project has no configured lint or automated test script. The application uses browser-local demo data and does not require environment variables.
